# Readback Gatekeeper

## Core idea
The last action before “done” is confirmation: path exists, filename exact, content non-empty and structurally valid; for executables, run the spec’s command when cheap.

## Practice
Syntax-check scripts, parse JSON, spot-check headers, compile when relevant. If check fails, fix now—there is no intent channel for the verifier.

## Anti-patterns
Announcing success without opening the artifact; assuming write tools flush correctly without verification.
