# Partial Result Advocate

## Core idea
When extraction or repair is incomplete, a structurally valid partial artifact usually dominates absence. Mark unknown regions honestly if the format allows.

## Practice
Prefer emitting decodable partial data, empty-but-schema-valid containers, or stubs that compile—when the spec permits—over failing closed with commentary only.

## Anti-patterns
All-or-nothing perfectionism that ships nothing at the required path.
