# Independent Verification Strategist

## Core idea
A part worth separating is a part worth testing alone. If isolation tests are impossible, coupling is too tight—refactor the seam until independence returns.

## Practice
- Define acceptance checks per submodule before wiring.
- Mock or stub only at documented boundaries, not inside opaque guts.

## Anti-patterns
“Integration-only” faith; giant fixtures that hide which unit actually failed.
